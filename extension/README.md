# Расширение Отклик

Chrome / Edge, Manifest V3. На странице вакансии hh.ru и Хабр Карьеры: match, письмо в буфер, запись в трекер. **Отклик на площадке не отправляется сам.**

Синк только с `https://otklik-gamma.vercel.app` (localhost в permissions нет — чужой сайт на :5173 не читает трекер).

## Установка (распакованное)

1. Открой `chrome://extensions` (или `edge://extensions`)
2. Включи «Режим разработчика»
3. «Загрузить распакованное расширение» → папка `extension` в этом репозитории
4. Открой https://otklik-gamma.vercel.app/app и заполни профиль (синк с расширением)
5. Открой вакансию на hh → кнопка **О** справа внизу

## Кнопки

- **Пакет: письмо + трекер** — копирует сопроводительное, пишет **черновик**, пытается вставить текст в форму, подсвечивает «Откликнуться». Статус `sent` ставь сам после реальной отправки.
- **Только письмо** / **Черновик** / **В форму** — без автоклика по apply.

Данные: `chrome.storage.local`, синхронизация с `localStorage` сайта Отклик.
