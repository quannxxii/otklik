# Отклик

Job search OS: Radar, трекер, канбан, follow-up, инсайты.

## Расширение Chrome / Edge

Папка `extension/`. На вакансии hh.ru и Хабр Карьеры: match, письмо, запись в трекер. Отклик на площадке не уходит сам.

1. `chrome://extensions` → режим разработчика → загрузить распакованное → `extension`
2. Открой приложение и заполни профиль
3. На странице вакансии кнопка **О**

Подробнее: `extension/README.md`

## Новое

- Онбординг за 4 шага
- Карточка отклика: вилка, контакт, заметки к собесу
- Инсайты: воронка, площадки, вилки
- Браузерные напоминания о follow-up
- PWA (можно «Установить приложение»)
- ⌘K палитра

## Запуск

npm install
